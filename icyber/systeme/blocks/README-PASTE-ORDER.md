# Wealth shop · systeme.io blocks (journey-website style)

Paste each file into its own **Custom HTML/CSS/JS** element, in this order. Set every section and row background to **Clear** and padding to 0, so the light/dark page background shows through.

1. `01-top-buttons.html`: My Amazon Store · Tools and Resources · All journeys · Dark/White mode
2. `02-bundle-card.html`: then add your systeme.io **"Get the bundle"** button right below it (bordeaux `#8E1F45`)
3. `03-free-trust-sheet-card.html`: TRUST Sheet – Financial Tracker (links to /free-financial-trust-sheet)
4. `04-about-liliane-card.html`: "Hey, I'm Liliane"
5. `05-journey-image.html`: upload `liliane-journey.webp` (or the `.png`), then replace `PASTE-JOURNEY-IMAGE-URL` with its link
6. `06-three-road-cards.html`: Career · Business · Wealth

In blocks 01 and 06, replace `PASTE-YOUR-JOURNEY-PAGE-URL` with the address of your journey page (e.g. `https://www.cybercnslt.com/your-journey-page`). The `#cybersecurity`, `#business`, `#finances`, `#tools` and `#journeys` endings open the right road directly.

Dark mode uses the same saved choice as your journey website, so a visitor who picked dark mode there sees this page in dark mode too.
